# 스크린샷

루트 README의 표가 이 폴더의 파일 4장을 가리킨다. **파일명이 곧 계약**이라 이름을 바꾸면
README의 이미지가 깨진다.

순서는 **PB가 상담 하나를 준비하는 흐름 그대로**다 — 오늘 시장 → 이 고객이 무엇을 들고
있나 → 무엇을 할까 → 들고 들어갈 종이.

| 파일명 | 화면 | 가는 길 |
| --- | --- | --- |
| `01-brief.png` | **① 상담 전 브리핑** | `/dashboard` 최상단. 지표 띠 + 3개월 추세 줄 + 고객 관련 종목 줄이 다 보이게 |
| `02-portfolio.png` | **② 고객 포트폴리오** | 고객 목록에서 한 명 클릭 → 보유 종목·비중·자산배분·위험 플래그 |
| `03-nba.png` | **③ Next Best Action** | 같은 고객 카드의 채팅에 질문 하나 → 답변 + 「다음 행동」 절 + `AI가 보는 정보` 패널 |

## 찍는 법

```bash
docker compose up -d
open http://localhost:3000/dashboard
```

- 브라우저 폭을 **1440px 안팎**으로. 너무 넓으면 카드 사이 여백만 커진다.
- macOS는 `⌘⇧4` → `Space` → 창 클릭이면 창만 깔끔하게 잡힌다(그림자 없이 받으려면
  클릭할 때 `Option`을 함께 누른다).
- 저장한 파일을 위 표의 이름으로 바꿔 이 폴더에 넣는다. 그다음 루트 README의 「화면」 절에서
  주석으로 들어 있는 **이미지 표로 갈아끼우면** 끝이다.

## ⚠️ 키가 있어야 온전히 나오는 화면

`.env`의 API 키가 비어 있으면 앱은 죽지 않고 그 자리를 **"미연결"이라고 말한다**(설계된 동작).
다만 스크린샷에는 빈 채로 남는다.

| 화면 | 필요한 키 |
| --- | --- |
| `01-brief` 지표 띠의 원/달러·국고채10년 | `ECOS_API_KEY` (미국 지표는 FRED라 키가 필요 없다) |
| `01-brief` 3개월 추세 줄 | `NAVER_*` + `ANTHROPIC_API_KEY` |
| `01-brief` 고객 관련 종목 줄 | `KRX_API_KEY` + 위 둘 |
| `03-nba` 답변 전체 | `ANTHROPIC_API_KEY` |

**`02-portfolio`와 `04-prep-memo`는 저장된 데이터만 읽으므로 키 없이 지금 바로 찍힌다.**
PDF는 화면을 거치지 않고 직접 열어도 된다:

```bash
open http://localhost:8000/api/prep-notes/<prep_id>/pdf     # 목록: /api/prep-notes
```

> **고객 이름이 화면에 보여도 괜찮다** — 이 저장소의 고객 50명은 전부 가상의 합성 데이터다
> (루트 README의 「데이터에 관한 고지」 참조). 다만 스크린샷에 **본인의 실제 API 키나
> 터미널 세션**이 함께 잡히지 않았는지는 넣기 전에 한 번 본다.
