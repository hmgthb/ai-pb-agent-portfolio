## 찍는 법

```bash
docker compose up -d                     # 4대 서비스 기동
open http://localhost:3000/dashboard
```

- **브라우저 폭을 1440px 안팎**으로 맞춘다. 너무 넓으면 카드 사이 여백만 커진다.
- macOS는 `⌘⇧4` → `Space` → 창 클릭이면 창만 깔끔하게 잡힌다(그림자 없이 받으려면
  `⌘⇧4` 후 `Space`를 누른 채 `Option`을 함께 누른다).
- 저장한 파일을 위 표의 이름으로 바꿔 이 폴더에 넣으면 README가 바로 렌더된다.
